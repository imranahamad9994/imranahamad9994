## 🤖 What makes me different — AI-augmented QA engineering

I don't just write test automation. I use **AI as a force multiplier** across my entire QA workflow — generating test scaffolding with **Claude Code**, writing utility methods with **OpenAI Codex**, and reviewing every output with a critical engineering eye before it ships.

> *AI writes the boilerplate. I write the strategy, the assertions, and the judgment calls.*

| Workflow step | How I use AI |
|---|---|
| Test case design | Prompt Claude to generate test scenarios from requirements, user stories, or Swagger specs |
| Code scaffolding | Claude Code generates POJO models, base classes, Page Objects, and utility methods |
| Assertion logic | Codex suggests assertion chains — I refactor for maintainability and reliability |
| Bug analysis | AI-assisted failure triage — Claude interprets response diffs and suggests root causes |
| Framework design | AI proposes patterns (POM, Singleton, Builder) — I evaluate, adapt, and implement |

This approach lets me deliver **higher test coverage in less time**, while maintaining full ownership of framework architecture and quality decisions.
