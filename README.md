## 🤖 What makes me different — AI-augmented QA engineering

I don't just write test automation. I use **AI as a force multiplier** in my QA workflow — generating test scaffolding with **Claude Code**, writing utility methods with **OpenAI Codex**, and reviewing every output with a critical engineering eye before it ships.

> *AI writes the boilerplate. I write the strategy, the assertions, and the judgment calls.*

Here's what that looks like in practice:

| Workflow step | How I use AI |
|---|---|
| Test case design | Prompt Claude to generate test scenarios from API docs or Swagger specs |
| Code scaffolding | Use Claude Code to generate POJO models, base classes, utility methods |
| Assertion logic | Codex suggests assertion chains — I refactor for maintainability |
| Bug analysis | AI-assisted failure triage — Claude interprets response diffs and suggests root causes |
| Framework design | AI proposes patterns (Page Object, Singleton, Builder) — I evaluate and implement |

This approach lets me deliver **higher test coverage in less time**, while maintaining full ownership of the framework architecture and quality decisions.
